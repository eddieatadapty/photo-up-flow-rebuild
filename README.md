# Photo Up! Growth Audit

**Live → https://eddieatadapty.github.io/photo-up-flow-rebuild/**

Five ideas to turn more Photo Up! users into subscribers, each built into a clickable version of Photo Up!'s own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask which photo they came to fix | +10–20% CR to purchase |
| 02 | Let them make one fix before the paywall | +5–15% CR to purchase |
| 03 | Put a year with 3 free days next to the $0.49 week | +10–15% ARPU |
| 04 | Catch the people who close the paywall | +10–15% ARPU |
| 05 | Open on your proof, not on Apple’s tracking prompt | +5–15% CR to purchase |

Every price, rating and feature comes from Photo Up!'s App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Photo Up! They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
